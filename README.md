## 📄 Assignment Summaries

### **Assignment 01 — NumPy Basics & Array Manipulation**

This assignment focused on understanding the fundamentals of NumPy.
I worked with array creation, slicing, indexing, reversing and basic operations. <br>
**What I learned:** how to handle numerical data using NumPy arrays.

---

### **Assignment 02 — Pandas, Feature Selection & Correlation Analysis**

Using the *AWCustomers.csv* dataset, I practiced data loading, exploring attributes, selecting useful features, and performing correlation-based analysis.<br>
**What I learned:** how to clean and analyse datasets, identify relationships between variables and prepare data for model building.

---

### **Assignment 03 — Regression using USA Housing Dataset**

This assignment involved working with the *USA_Housing.csv* dataset.
I separated features and target values, explored the dataset and prepared inputs for regression.<br>
**What I learned:** the regression pipeline preprocessing, splitting data and understanding how input features influence continuous target predictions.

---

### **Assignment 04 — Web Scraping with Requests & BeautifulSoup**

I used `requests` and `BeautifulSoup` to scrape structured information from web pages (e.g., IMDb-style listings).
The task involved sending HTTP requests, parsing HTML, extracting rows and storing results. <br>
**What I learned:** how web scraping works, how to handle page content and how to convert scraped data into analysable formats.

---

### **Assignment 05 — Image Dataset (Digits) & ML Classification**

Using the sklearn **digits** dataset, I explored image shapes and processed pixel data.
The assignment was divided into PART-A and PART-B, covering ML classification models and possibly dimensionality reduction. <br>
**What I learned:** how to work with image datasets, apply classification models (like KNN/SVM) and evaluate predictions.

---

### **Assignment 06 — Regularized Regression (Lasso & Ridge)**

This assignment involved generating synthetic datasets and applying Lasso and Ridge regression models.
I compared model performance using R² and MSE. <br>
**What I learned:** the concept of regularization, preventing overfitting and the difference between L1 and L2 penalties.

---

### **Assignment 07 — Iris Dataset & Classification Models**

Using the classic Iris dataset, I implemented classification algorithms and evaluated them using accuracy, confusion matrices and classification reports. <br>
**What I learned:** multiclass classification workflow, model comparison and interpretation of evaluation metrics.
